Smart Notes Study Guide Builder

About the Project

Smart Notes Study Guide Builder is a simple web application that helps students write, save, search, and revise their study notes.

Features

- Create study notes
- Save notes
- Search notes
- Generate short revision summaries
- Delete saved notes

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Enter a note title.
2. Type your study notes.
3. Click Save Note.
4. Click Create Summary to get a short summary.
5. Search your notes whenever needed.

Project Objective

The objective is to help students organize study materials and revise topics easily.
